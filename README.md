## מה נעשה מסביבת הענן ומה לא

**נעשה:** איסוף 62 מודעות אמיתיות דרך חיפוש רשת (שמות, אזורים, קישורים, 17 טלפונים, הערות פרופיל), כל הטיוטות, הסקריפטים וההוראות.

**לא ניתן מסביבת הענן (חסימת רשת/דפדפן):**
1. גישה ישירה ל-weekend.co.il / zimmer.co.il (403) → **מחירי לילה ומס' יחידות לא אומתו** לרוב הרשימה. לפני פנייה: לפתוח את המודעה ולוודא מחיר 1,200 ₪+.
2. הורדת תמונות הדמו → ידנית לפי `photos/README.md` (5 דקות).
3. OpenArt → בדפדפן שלך לפי `clips/README.md`.
4. בדיקת אינסטגרם לכל צימר → ידנית לפני שליחה (עמוד חזק = לדלג).

## הצעד הבא שלך (לפי תוכנית 14 הימים)

1. להוריד תמונות דמו → להנפיש ב-OpenArt → `./scripts/make-demo.sh`
2. לשלוח את הודעת הגיוס ל-8–10 עורכים בפייבר (נוסח ב-CLAUDE.md סעיף 5)
3. לאמת מחיר+אינסטגרם ל-20 הראשונים ב-prospects.csv → לשלוח מ-outreach-drafts.md
